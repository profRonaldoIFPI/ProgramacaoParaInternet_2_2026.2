0. Instalar o Bruno, Insomnia ou Postman para testar a API.

1. No terminal, execute:
    - `npm init -y`.
    - `npm install express`.
2. Edite o arquivo `package.json`:
    - Modifiqua a chave `type` para `module`;
    - Adicione o script `"dev": "nod -watch app.js"`.
    - `main: "app.js"`
3. Crie o arquivo `app.js`.
