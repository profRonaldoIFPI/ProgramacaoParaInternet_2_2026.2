---

## 📌 Sobre a Disciplina

A disciplina de **Programação para Internet II** aborda conceitos avançados e práticos de desenvolvimento do lado do servidor (*Backend*), capacitando os alunos a projetar, desenvolver e integrar serviços e APIs robustas para a web.

### 🎯 Objetivos de Aprendizagem

- Compreender o funcionamento da arquitetura Cliente-Servidor e protocolo HTTP.
- Construir APIs **REST / RESTful** eficientes e escaláveis.
- Gerenciar rotas, controladores e regras de negócio no servidor.
- Integrar a aplicação com Sistemas de Gerenciamento de Banco de Dados (SGBDs).
- Aplicar conceitos de autenticação, autorização e segurança no backend.
- Adotar boas práticas de organização de código e padrões de projeto (Design Patterns).

## 🛠️ Ferramentas e Pré-requisitos Recomendados

Para acompanhar as aulas e executar os exemplos localmente, recomenda-se a instalação das seguintes ferramentas:

1. **Editor / IDE:**
   - [Visual Studio Code (VS Code)](https://code.visualstudio.com/)

2. **Gerenciador de Versão:**
   - [Git](https://git-scm.com/)

3. **Ambiente de Execução (Runtime/Linguagem):**
   - [Node.js](https://nodejs.org/) (versão LTS recomendada)

4. **Clientes HTTP para Teste de APIs:**
   - [Postman](https://www.postman.com/) / [Insomnia](https://insomnia.rest/) / Extensão *Thunder Client* ou *REST Client* no VS Code.

## 🚀 Como Utilizar Este Repositório

### 1. Clonar o Repositório

Para obter uma cópia local de todos os exemplos, abra seu terminal e execute:

```bash
git clone https://github.com/seu-usuario/ProgramacaoParaInternet_2_2026.2.git
```

### 2. Atualizar o Código Local

Como novos exemplos serão adicionados a cada aula, lembre-se de sincronizar seu repositório local executando:

```bash
cd ProgramacaoParaInternet_2_2026.2
git pull origin main
```
